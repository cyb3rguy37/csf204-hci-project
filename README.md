# CSF204 - HCI Project
The IxD Synthesis Challenge

Develop wireframes and prototypes of responsive websites of a cybersecurity firm using CSS and HTML technologies in groups of twos. These artefacts should consider and bear all the aspects of UI/UX that were learnt during the semester. The wireframe should be made using a wireframe software like Balsamiq. The responsive website prototype  will be developed using CSS and HTML.
